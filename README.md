# 📊 Chattiq Meta Ads – Audience Performance Analysis

A digital marketing analytics project focused on comparing Meta Ads audience performance for **Chattiq**, an AI conversation assistant.

The project analyzes campaign performance across three audience segments and uses Excel to identify differences in engagement and traffic efficiency.

## 🎯 Project Objective

The objective was to compare the performance of different audience segments and understand:

- Which audience generated higher engagement?
- Which audience had a lower CPC?
- Which audience generated more link clicks?
- How did CTR vary across audiences?
- What insights can be used for future campaign optimization?

## 👥 Audiences Analyzed

The campaign compared three audience segments:

- Travel & Tourism
- Marketing Agencies
- Doctors / Healthcare

## 🛠️ Tools Used

- Meta Ads Manager
- Microsoft Excel
- Data Analysis
- Excel Charts & Dashboard

## 📊 KPIs Analyzed

The analysis focused on:

- Total Spend
- Impressions
- Reach
- Link Clicks
- Link CTR
- CPC (All)

## 📈 Campaign Summary

| KPI | Result |
|---|---:|
| Total Spend | ₹249.56 |
| Impressions | 956 |
| Reach | 859 |
| Link Clicks | 14 |
| Overall Link CTR | 1.46% |
| Overall Link CPC | ₹17.83 |

## 🔎 Audience Performance

### Travel & Tourism

- CTR: **0.59%**
- CPC (All): **₹32.25**
- Link Clicks: **6**

### Marketing Agencies

- CTR: **1.07%**
- CPC (All): **₹20.07**
- Link Clicks: **6**

### Doctors / Healthcare

- CTR: **0.30%**
- CPC (All): **₹144.93**
- Link Clicks: **2**

## 💡 Key Insights

- Marketing Agencies recorded the highest observed CTR at **1.07%**.
- Marketing Agencies also recorded the lowest CPC (All) at **₹20.07** among the three audiences.
- Travel & Tourism and Marketing Agencies generated **6 link clicks each**.
- Doctors / Healthcare generated **2 link clicks** and had the highest CPC (All) at **₹144.93**.
- The campaign generated **14 link clicks** from **₹249.56** in spend.
